# Data layout

`derived/analysis_outputs/` contains the retained intermediate tables required by analysis and figure scripts. `derived/supplementary_tables/` contains the publication Supplementary Tables S1–S11 as CSV files. These files were copied without recalculation.

`external_metadata/` contains small, version-specific metadata and mapping files needed for reproducibility, including the exact DepMap 24Q2 `Model.csv`. Large public source matrices are not redistributed. Download them from the original providers and place them under `data/source/` following `docs/DATA_SOURCES.md`, or set `ORGANOID_SOURCE_ROOT` to a compatible source-data root.

Third-party data remain subject to their original licences and terms of use.
